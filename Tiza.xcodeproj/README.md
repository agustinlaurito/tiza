# Whiteboard Community — Open Source, Free, and Built Together

Whiteboard Community is an open‑source, privacy‑respecting whiteboard app designed for teams, classrooms, and creators. It’s free forever and built by and for the community.

## Why this project exists

With Microsoft retiring MS Whiteboard for many users and workflows, a gap has opened for a simple, modern, and truly community‑owned alternative. This project aims to:

- Provide a dependable, long‑term replacement for MS Whiteboard
- Keep core features free and accessible to everyone
- Embrace open standards and transparent development
- Welcome contributions from educators, students, designers, and developers alike

## Key principles

- **Free and open source**: The core will always be free to use. The source code is open for anyone to study, modify, and improve.
- **Community‑driven**: Decisions are discussed openly. We value constructive feedback and collaboration.
- **Privacy‑first**: No surprise analytics. Clear, opt‑in telemetry (if any) and local‑first defaults whenever possible.
- **Cross‑platform mindset**: Aim for great experiences across Apple platforms first, and embrace portability where it makes sense.

## Features (current and planned)

- Infinite canvas with smooth pan and zoom
- Pen, highlighter, shapes, and eraser tools
- Sticky notes and text boxes
- Image import (drag & drop where supported)
- Multi‑select, group, and align
- Undo/redo history
- Board templates (planned)
- Real‑time collaboration (planned)
- Export to PDF/PNG/SVG (planned)
- iCloud/Cloud sync options (planned)

If you’re exploring the codebase, start with the app entry point and the canvas/board modules. We keep components small and testable.
